##  Описание проекта
Данное приложение представляет собой систему управления учебным процессом в университете. Оно позволяет управлять данными студентов и курсов, обеспечивая надежное хранение информации и взаимодействие между сущностями.

##  Что было реализовано
В ходе работы над финальным проектом были выполнены следующие задачи:

1.  **Многоуровневая архитектура:** Разделение на Controller, Service, Repository и DTO для чистоты кода.
2.  **Работа с базами данных:**
    * **PostgreSQL:** Хранение основных данных (студенты, курсы).
    * **MongoDB:** Использование NoSQL для логирования или системы уведомлений.
3.  **Документация API:** Интеграция **Swagger (OpenAPI)** для удобного тестирования эндпоинтов.
4.  **Асинхронность (@Async):** Реализована имитация отправки уведомлений, которая работает в фоновом потоке, не блокируя основной поток приложения.
5.  **Контейнеризация:** Написаны `Dockerfile` и `docker-compose.yml` для автоматического развертывания всего окружения (приложение + 2 базы данных) одной командой.
6.  **Мониторинг:** Подключен **Spring Boot Actuator** для отслеживания состояния приложения.

##  Технологии
* **Java 21** & **Spring Boot**
* **Базы данных:** PostgreSQL (основная), MongoDB (для логов/уведомлений)
* **API Documentation:** Swagger UI (OpenAPI)
* **Контейнеризация:** Docker & Docker Compose
* **Дополнительно:** Spring Security, Actuator, Async Tasks

##  Структура проекта
Проект организован по стандартной структуре Spring Boot, но с персонализированным именованием пакетов:

* **`src/main/java/com/example/baurzhankyzy_aruzhan`**
    * `AruzhanController`: Обработка входящих HTTP-запросов.
    * `AruzhanService`: Вся бизнес-логика и вызовы асинхронных методов.
    * `AruzhanModel`: Описание таблиц базы данных (Entity).
    * `AruzhanDto`: Объекты для передачи данных между слоями.
    * `AruzhanRepository`: Интерфейсы для связи с базами данных (JPA & MongoDB).
    * `AruzhanConfig`: Конфигурация Swagger и системных настроек.
* **`src/main/resources`**
    * `application.properties`: Настройки подключения к БД и портов.

##  Как запустить проект
Проект полностью настроен для запуска через Docker. Вам не нужно устанавливать базы данных локально.

1. Убедитесь, что у вас установлен Docker Desktop.
2. Склонируйте репозиторий.
3. В корне проекта выполните команду:
   ```bash
   docker-compose up --build

### Тестирование проекта

**1. Проверка запуска:**
* Откройте терминал в IntelliJ IDEA.
* Введите команду: `docker-compose up`.
* Если в логах побежали строчки и в конце написано `Started BaurzhankyzyAruzhanApplication`, значит контейнеры с базой и приложением работают.

**2. Тест асинхронности:**
* Проверьте логи в IntelliJ после создания студента. Если там появилось сообщение "Sending notification for student: Aruzhan" (которое мы делали через `@Async`), значит асинхронная часть тоже работает.

**3. Тест Actuator (Health Check):**
* Перейдите на `http://localhost:8080/actuator/health`.
* Если видите `{"status":"UP"}`, значит приложение чувствует себя отлично.
